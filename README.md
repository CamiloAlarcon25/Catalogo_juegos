# Catálogo de Juegos

Aplicación web desarrollada con **HTML**, **CSS** y **JavaScript** para mostrar un catálogo de juegos de mesa y juegos terapéuticos de manera sencilla, moderna e intuitiva.

## Características

- 🎲 Catálogo dinámico de juegos.
- 🔍 Buscador en tiempo real.
- 🏷️ Filtro por categorías.
- 📄 Página individual para cada juego.
- 📦 Indicador de disponibilidad (Stock / Sin Stock).
- 📱 Diseño responsive para computador, tablet y móvil.
- 🎨 Interfaz moderna y fácil de usar.
- 📷 Contacto mediante Instagram y Facebook.

## Funcionalidades

### Catálogo

- Visualización de todos los juegos disponibles.
- Orden automático por nombre.
- Tarjetas con imagen e información principal.

### Buscador

Permite buscar juegos instantáneamente por nombre.

### Categorías

Filtrado por tipo de juego:

- Familiares
- Terapéuticos
- Rapidez
- Estrategia
- Infantiles

### Ficha del juego

Cada juego cuenta con una página individual donde se muestra:

- Imagen
- Categoría
- Edad recomendada
- Número de jugadores
- Duración
- Descripción
- Objetivo
- Habilidades
- Contenido de la caja
- Estado del stock

### Contacto

Los usuarios pueden consultar:

- Precio
- Disponibilidad
- Recomendaciones

A través de:

- 📷 Instagram
- 📘 Facebook
